MouseLimbLab v1.1.5 支持按速率曲线手动划定摆动相，整段视频输出一幅连续姿态图。

- 不分行、不抽样，保留整段视频的有效姿态。
- 在速率曲线上拖选摆动区间，支持多个区间、精确修改起止帧、删除和清空。
- 保存后只按手动选区着色：红色摆动、黑色支撑；起止帧均包含。
- 同步更新 PNG/PDF、逐帧相位和四点周期统计，选区随项目保存并导出 CSV。
- 分析后保持窗口打开，可继续下一段视频。

## English

Draws the entire recording as one continuous limb sequence. Select swing regions
on the speed curve, edit inclusive frame bounds and save. Manual regions replace
automatic colouring and persist in the project and CSV exports. Four-point cycle
metrics are recomputed; ALMA retains its official event definitions.
