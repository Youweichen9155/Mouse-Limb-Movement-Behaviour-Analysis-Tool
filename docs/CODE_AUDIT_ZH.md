## ALMA 接入规则

ALMA 作为可切换的分析方法，独立检测周期并生成结果。

1. 官方函数文件原样保存，测试核对 SHA256；适配层只处理格式、缺口、来源、结果复核。
2. 六个点全部提供后才运行；低置信坐标先置空、只插短缺口、长缺口分段。
3. ALMA 上游筛选未通过的周期保留在原始表并标为排除；通过筛选且经人工纳入的周期进入鼠内汇总。
4. 上游 percentage 列保留原值，同时提供明确的比例/百分数两种新增字段。
5. `find_drag` 沿用上游末尾窗口处理，部分末尾拖曳帧可能被筛除。结果记录官方提交版本，复核时可结合原视频检查这些帧。
6. 官方 v2 将 DTW 替换为重采样距离；文档与报告明确说明。
7. 未知帧率、错误数据格式、四点数据切到 ALMA、悬空数据切到 ALMA 均报可理解的错误，不静默回退到另一引擎。

## 验证范围

测试覆盖源帧缺失/重复、长缺口、慢动作比例、悬空指标、静止无周期、DLC 左右与置信度、源文件不变、动物汇总、追踪漏检保帧、两个引擎独立调用，以及 ALMA 官方示例与直接函数调用数值一致性。

三份既有逐帧坐标用于检查集成流程。官方示例以设定的 120 fps 比较适配层与官方函数的数值一致性。

自动分析与人工确认分开。平台与打包验证结果见同目录 `VALIDATION.md`。
